SAUREK'S CLOSET - INSTALLATION

Version 4.1.1 requires renderer 40101 (DLL 4.1.1).
Simple mode changes your equipped main hand, off hand and ranged slots.
Check Advanced mode to choose separate carried items and tune placement.
Both modes preserve your saved choices. See WEAPON-MENU.md.
Bags has five fixed customizable slots with eight model choices.
The Cloth Pouch includes Burgundy, Navy, Ochre and Olive color options.
Click an empty slot to open its visual model picker and tuner. A bag is added
only after you choose its model. Choose a color and Back, Left hip or Right hip,
then adjust its fit. All five slots stay visible; removing one leaves it empty.
Save Fit stores the bag's fit in the current look. See BAGS-MENU.md.
The wardrobe Save button updates your active saved look, including live previews
and bag tuning. New looks open Saved Looks for naming. Edited looks retain their
name with (Edited), and switching looks warns before discarding unsaved changes.
Save is greyed out while there are no unsaved changes. Preview rotation alone
does not enable it.
Right-click the minimap button for Toggle Addon or Refresh Addon.
Refresh Addon reloads the interface while retaining current appearance and bag
fit changes in your unsaved look. Drag either preview to rotate it.

INSTALLING OR UPDATING

Install both the addon and DLL from version 4.1.1, then fully restart the game.
The /reload command cannot replace a loaded DLL. Character equipment icons
and inventory tooltips now always use real equipment. Cosmetic appearances
remain visible on the world character and 3D previews.

1. Fully close World of Warcraft.
2. Copy the SaureksCloset addon folder into Interface/AddOns.
3. Open your main WoW folder: the folder containing WoW.exe.
4. Copy SaureksCloset.dll from this instructions folder into that WoW folder.
   Replace the existing SaureksCloset.dll if asked.
   It belongs beside WoW.exe, NOT inside Interface or AddOns.
5. Open dlls.txt in the WoW folder. Add this line after VanillaHelpers.dll
   if it is not already there:

   SaureksCloset.dll

   Keep your other DLL entries. Do not add duplicate entries.
6. Start WoW through VanillaFixes and enable Saurek's Closet in AddOns.

VanillaFixes and VanillaHelpers must already be installed.
This is for the supported Windows 1.12.1 client, build 5875.

The DLL copy in this instructions folder is only for installation;
WoW will not load it from here. After replacing a DLL, fully restart the
game. The /reload command only reloads the addon.

Version Details should show addon 4.1.1, loaded DLL 4.1.1, and required
DLL 4.1.1. These are the compatible versions for this update.
